# Learning Design — RETIRED

The multiple-choice training mode (candidate moves per turn, best/worst
mixes, points feedback) was removed. Every game is free play: you play any
move, the bot replies, the winrate graph records each move and doubles as
the review slider. Rated play is unchanged — every game counts unless
unranked (see [RATINGS.md](RATINGS.md)).

Kept as a pointer so old links land somewhere honest. The implementation
is gone: no candidate queries, no per-move evaluations, no feedback UI.
